# AI Resume Analyzer

An AI-powered Resume Analyzer built using Machine Learning and NLP.

## Features

- Resume Category Prediction
- ATS Match Score
- Skill Extraction
- Missing Skill Detection
- PDF Resume Upload
- Job Description Analysis

## Technologies Used

- Python
- Scikit-Learn
- Streamlit
- Pandas
- PDFPlumber
- TF-IDF Vectorization
- Naive Bayes Classifier

## How to Run

```bash
pip install -r requirements.txt
python -m streamlit run app.py
```
